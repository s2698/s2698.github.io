Add the bot

Adds the sign-up bot to a Discord server. You need the Manage Server permission on that server.

  1. Press Add the bot to a server. Discord opens in a new tab.
  2. Pick the server and press Continue, then Authorise. The permissions are already ticked.
  3. Come back here and press Load from Discord below.
Add the bot to a server
What the bot can do
  • See channels and read the history of the ones it posts in
  • Send messages with embeds (the sign-up posts)
  • Mention roles and @everyone, only when you tick them on New event
  • Add the /signups and /mysignups commands

It can't kick, ban, delete other people's messages or change server settings.
